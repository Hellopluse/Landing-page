# ⚡ Hello Pulse

**Plateforme de Co-création Assistée par IA** — *Libérez votre potentiel créatif, amplifié par l'intelligence artificielle.*

---

## 🌟 Vision

Hello Pulse a pour ambition de devenir la référence mondiale de la **co-création assistée par IA**. Notre plateforme permet à chaque équipe de transformer ses sessions de brainstorming en plans d'action concrets, en éliminant les barrières technologiques, linguistiques ou physiques.

> "L'IA ne remplace pas la créativité humaine, elle l'amplifie."

---

## 🚀 Fonctionnalités Clés

### 🧠 Équipe d'Agents IA Spécialisés
Fini le chatbot générique. Hello Pulse met à votre disposition des experts dédiés :
- **Le Facilitateur** : Maître du Design Thinking et des méthodes de brainstorming (SCAMPER, 6 chapeaux).
- **Le Recherchiste** : Expert en veille stratégique et analyse de marché en temps réel.
- **Le Stratège Business** : Génère automatiquement vos SWOT et Business Model Canvas.
- **L'Orchestrateur** : Transforme vos idées en roadmaps et tickets actionnables.

### 🪆 Architecture "Poupées Russes"
Une organisation hiérarchique infinie pour structurer vos projets les plus complexes. Naviguez naturellement de la vision d'ensemble aux détails les plus granulaires.

### 🎨 Dual Spaces : Canvas & Studio
- **Canvas (Phase de Divergence)** : Un espace libre pour l'idéation, le brainstorming et la capture spontanée.
- **Studio (Phase de Convergence)** : Un environnement structuré pour transformer les concepts en livrables professionnels.

### ♿ Inclusivité Native (Accessibility-First)
Conçu pour tous dès le premier jour :
- **Support Vocal Complet** : Interaction TTS/STT pour une utilisation sans écran.
- **Traduction Instantanée** : Collaborez dans plus de 200 langues sans friction.
- **Inclusivité Cognitive** : Interface optimisée pour les profils dyslexiques et neuroatypiques.

## 🛠️ Stack Technique

### Frontend
- **Framework** : [Vite](https://vitejs.dev/) + [React](https://reactjs.org/)
- **Langage** : [TypeScript](https://www.typescriptlang.org/)
- **Styling** : [Tailwind CSS](https://tailwindcss.com/)
- **Composants** : [shadcn/ui](https://ui.shadcn.com/)
- **Animations** : [Framer Motion](https://www.framer.com/motion/)

### Backend (Architecture Cible)
- **Framework** : FastAPI (Python)
- **Intelligence** : Orchestration d'Agents (LangGraph / CrewAI)
- **LLMs** : Claude 3.5 Sonnet / GPT-4o
- **Base de Données** : PostgreSQL + Vector DB (pgvector)

## 💻 Installation Locale

1. **Cloner le projet**
   ```bash
   git clone https://github.com/EngineerProjects/hellopulse.git
   cd hellopulse
   ```

2. **Installation & Lancement (Frontend)**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
   L'application sera accessible sur `http://localhost:8080`.
